# 情绪 → 音乐规则

> 示例内容,可在 Profile 页随时编辑。移动端心情 chips 对应这里的心情。

| 心情 | 风格 | 节奏 | DJ 做法 |
|---|---|---|---|
| Chill | City Pop、Lo-fi、爵士 | 60-100 BPM | 音量偏低,串词少而缓 |
| Happy | 流行、放克、独立摇滚 | 100-140 BPM | 串词可以活泼一点 |
| Melancholy | 民谣、后摇、钢琴 | 60-90 BPM | 先共情,不立刻切高能 |
| Lonely | 温暖人声、慢板灵魂 | 60-90 BPM | 串词有陪伴感,短句 |
| Nostalgic | 华语经典、City Pop | 70-110 BPM | 串词可以聊聊回忆 |
| Dreamy | 氛围电子、梦泡、后摇 | 70-100 BPM | 串词留白多一点 |
